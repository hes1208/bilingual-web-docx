# 分批并行翻译协议

## 派发规则

**一个子 agent 处理一整批（默认 5 块），不要一块一个 agent。**

固定开销（读术语表、读提示词、写校验、回话）约 3–8k token，与翻译内容无关。
65 块一块一个 agent，等于把这份开销付 65 遍；按 5 块一批只需付 13 遍。
实测这一项占总成本一半以上。

批次清单由 `chunk.py` 生成在 `_batches.json`，照 `batch` 字段派发即可。
每批 5 块约 2.5–3 万英文字符，一个子 agent 一次可以完成。

并发建议：一次并行 6–9 个 agent，跑完一批再发下一批。不要一次全压上去
（会互相排队，且失败后难以定位）。

## 提示词模板

> 复制以下内容，替换 `{{...}}` 占位符后派给子 agent。

```
你是学术出版 / 技术文档领域的专业译者，把 {{DOMAIN}} 的英文原文译为简体中文。

任务：处理第 {{BATCH_NO}} 批，共 {{N_CHUNKS}} 个文件。

步骤：
1. 用 Read 读取 {{WORKDIR}}/glossary.md，严格遵守其中的术语对照与翻译规则。
2. 依次读取以下文件（每个文件含 items 数组，每项有 i 与 en 两个字段）：
{{CHUNK_FILES}}
   例：D:/work/xxx/chunks/c006.json
3. 对每个文件，把 items 里每个 en 片段翻译成简体中文，输出 zh 数组：
   - 项数、顺序必须与 items 完全一致
   - 严禁合并、拆分、遗漏、新增
   - 一个文件对应一个 zh.json，不要混在一起
4. 保留 markdown 结构：`# ` 标题、`- ` / `1. ` 列表、`**粗体**`、`*斜体*`、
   `[文本](URL)` 链接、`|` 表格语法。
   - 所有 URL 原样保留，只翻译链接的显示文本
   - 数字、百分比、日期、机构名、期刊名、政策名、缩写（ORCID / APC / DOI / FAIR 等）保留原样
   - 表格里的 `<br>` 换行标记必须原样保留
   - 纯分隔线（连续下划线）原样保留，不要译成文字
5. 不要添加任何译者注、说明、前言或总结。

输出：对每个输入文件 cNNN.json，用 Write 写入同目录 cNNN.zh.json，
内容为严格合法的 JSON（UTF-8，不要 markdown 代码块包裹）：
{"chunk": NNN, "zh": ["译文1", "译文2", ...]}

JSON 字符串内的英文双引号必须转义，换行用 \n。

校验：全部写完后，用 Bash 执行
  cd {{WORKDIR}} && python scripts/verify.py {{BATCH_NO}}
确认输出 BAD=[]。若某块有 COUNT / EMPTY / UNTRANSLATED，修正后重跑，
直到 BAD=[] 为止。

最后只需回复一行：完成，批次={{BATCH_NO}}，块数={{N_CHUNKS}}，项数合计=X
```

## 质量规则（可写进术语表顶部）

- **术语一致优先于文采**：同一概念全篇只用一种译法。
- **保留可执行信息**：字数上限、文件格式、数量限制、期限、邮箱、模板名称一字不能改。
- **政策名与人名不译**：如 Matters Arising、CONSORT、Plan S、ORCID 保留原文，
  必要时在首次出现处加中文括注。
- **表格逐格对应**：列数与行数必须与原文一致，不能为了"读起来顺"合并单元格。
- **列表编号保留**：`1.` `2.` 必须与原文对应，否则与正文里的"见第 3 条"会错位。

## 常见失败与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| COUNT 不符（少项） | agent 把相邻短句合并了 | 重派该块，强调"项数必须完全一致" |
| UNTRANSLATED | 该块全是 URL 或符号，属正常 | 若含英文单词则重派 |
| EMPTY | JSON 里漏了空串项 | 重派该块 |
| BADJS | 引号未转义 / 多余逗号 | 让 agent 用 json.dumps 风格重写，或本地脚本修复 |
| 表格结构错乱 | 译文中 `\|` 未转义 | 强调"表格分隔符用 `\|`" |

## 术语表整理时机

**在切块之后、派发之前**整理。先看 `_chunks_report.txt` 的篇目清单，把高频术语、
专有政策名、机构名、缩写列进 `glossary.md`（模板见 `glossary-template.md`）。
术语表是所有 agent 的共享前提，漏掉会导致各批译法不一致，后期返工成本远高于前置整理。
